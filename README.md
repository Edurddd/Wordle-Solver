# Wordle-Solver
Python Console Wordle Solver. At some point I will make a GUI for the program and optimize it but putting this up for right now

Got txt from @dracos on github

The first guess will be a random word that doesn't have repeat letters. The user then enters that word into their wordle and gives the program information based on the game feedback. 
It will not ask information for letters that are already green.
Enter 'x' if a letter is gray 'y' for yellow and 'g' for green
